# Screen board (#147) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Draw `docs/pipeline/screen.d2`, the board that shows how `bot screen` turns the universe into a ranked shortlist (Capa B): snapshot and derived ratios, coverage gate, the 16 rules with the `damodaran_value` thresholds, the two-pass ranking, persistence and reports. CI renders it to `screen.svg`; `pipeline.d2` links it.

**Architecture:** One new d2 board pulling the shared classes with `...@classes`. Top-level entry point, files, outputs, a `duckdb` container with the seven tables read or written, one `analyze_stage` node for the discounted cash flow (DCF) seam, and seven layer containers (`snapshot`, `coverage_gate`, `quality_gates`, `value_indicators`, `trap_detection`, `ranking`, `persist_and_report`). Each rule is a `decision` keyed by its registry name inside its layer container. Every name from the code is cited with a directive in a d2 line comment. Tests in `tests/unit/test_pipeline_diagram.py` pin required citations (rules derived from the registry, params from the preset YAML), node keys and classes, formulas, pass directions and gap notes. Rendering only in the `pipeline-diagram` workflow (no d2 locally).

**Tech Stack:** d2 v0.9.0 + TALA (CI only), Python 3 / pytest, `docs/pipeline/check.py` (stdlib).

**Spec:** GitHub issue #147 (child of story #144), its "Inherited decisions" section, and `docs/pipeline/README.md` (directive syntax).

## Global Constraints

- Board file: `docs/pipeline/screen.d2`; first line `...@classes`; then `direction: down`; imports no other board; `class:` is a node's first attribute.
- Only the nine classes of `classes.d2`. No new shapes, no styles.
- A note is a child of the node it annotates, label `|md ... |`. A `gap` note is a single-line `|md Gap: ... |`.
- English; domain words exactly as in `CONTEXT.md` (universe, sector benchmark, coverage gate, quality gates, value indicators, trap detection, margin of safety, measured company, listing currency, ...).
- Formulas in plain math with Unicode operators (`×`, `÷`, `−`, `≤`, `≥`), never function names.
- Every acronym (regex `\b[A-Z][A-Z0-9]+\b`) is a key of `_ACRONYMS` or `_ACRONYMS_EXEMPT` and its expansion appears earlier in the board or on the same line. Write `P/E`, never `PE`; never write `NULL`, `TRUE`, `FALSE`, `UUID` in visible text (use lower case words).
- Directives live in `#` comments trailing the line whose visible text they check, never inside `|md ... |`. A `@param` / `@const` value must be visible on that same source line. Directive arguments fully qualified. No `@` starting a word anywhere else.
- A label line is at most ~70 characters; longer labels break with `\n` inside double quotes; never put an acronym right after `\n` (start the line with a lower-case word).
- Every edge carries a label. Edges are declared at top level, after the nodes, with dotted paths.
- Do not touch `src/`. Never hand-write or edit an SVG or `rendered.sha256`.
- Quality bar: `uv run ruff check . && uv run mypy src && uv run pytest -q` green, and the `pipeline-diagram` workflow green on the head commit.
- Commits: board work `docs(#144): ...` (story convention); pipeline stages `test(#147)`, `fix(#147)`, `chore(#147)`.

## Review Focus

1. **A pass direction drawn backwards** (the YAML comments say `Net Debt / EBITDA < 4.0` but the code passes `≤ 4`; goodwill passes `≤ 0.5`; coverage `≥ 2`; dilution `≤ 5%`). Pinned two ways in Task 1: `_SCREEN_TEXT` substrings fix the operator on the board, and `test_screen_rule_directions_match_code` evaluates each comparison rule exactly at its threshold and checks that the board's operator is inclusive (`≤`, `≥`) exactly when the code passes at equality.
2. **A preset threshold changed without the board.** `@param` directives + `_REQUIRED_PARAMS["screen"]` derived from the YAML; `test_every_directive_is_valid` names the rule (`@param min_market_cap.minimum_usd: value ... not shown`).
3. **A new rule registered without a node.** `_REQUIRED_RULES["screen"] = set(registered_rules())` plus `test_screen_rules_are_decisions`.
4. **An acronym slipping in unexpanded** (ROE, ROIC, EV, BV, EPS, CAGR are new). `test_acronyms_are_expanded` (existing) + new `_ACRONYMS` entries.
5. **A d2 syntax error only CI sees.** Copy syntax only from `refresh.d2`, which renders; Task 4 reads `--log-failed`.

## Node map (all tasks use these exact keys)

Top level:
- Source order (the acronym test reads the board top to bottom): `cli`, files, `duckdb`, `analyze_stage`, outputs, then the containers in layer order, then edges. Placeholders are lower case (`--preset name`, `--config path`, `<preset>.md`): `NAME`, `PATH`, `PRESET` would match the acronym regex and are not exempt.
- `cli` (step) `@symbol bot.cli.screen`, `@symbol bot.screener.config.load_screener_config`: `bot screen --preset name (default damodaran_value) [--top N]` (`N` is a single capital, not matched); note `cli.options`: `--config path` overrides `--preset`; missing file → exit code 2; the preset lists the rules of the three layers and the ranking weights; `deep_value` and `qarp` are the two other presets, changing thresholds and weights; this board shows `damodaran_value`.
- Files (class `file`): `damodaran_value` `@file config/presets/damodaran_value.yaml`, `deep_value` `@file config/presets/deep_value.yaml`, `qarp` `@file config/presets/qarp.yaml`, `assumptions` ("config/assumptions/TICKER.yaml, manual overrides") `@symbol bot.valuator.assumptions.conventional_override_path`.
- `duckdb` container, one `store` child per table, each on its own line `# @table <name>`: `companies`, `financials_annual`, `prices_daily`, `currencies`, `damodaran_industry`, `damodaran_country`, `screener_candidates`.
- `analyze_stage` (step) `@symbol bot.valuator.analysis.analyze`: "analyze stage valuation: intrinsic value by discounted cash flow (DCF), see the analyze board".
- Outputs (class `output`): `report_md` ("reports/YYYY-MM-DD/screen/<preset>.md"), `report_csv` ("reports/YYYY-MM-DD/screen/<preset>.csv").

`snapshot` container ("1. snapshot per company"):
- `load` (step) `@symbol bot.screener.engine.run_screen`: every company of `companies`; its non-restated `financials_annual` rows, oldest first (latest row = newest fiscal year); newest `prices_daily` close and newest market cap (each from its own newest non-empty row).
- `region` (decision) `@symbol bot.screener.engine._resolve_region`, `@const bot.screener.engine.DEFAULT_REGION`: country → Damodaran dataset region via the newest `damodaran_country` row; no country or no mapping → US.
- `tax` (decision) `@symbol bot.screener.engine._resolve_tax_rate`, `@const bot.screener.engine.DEFAULT_TAX_RATE`: label starts "tax rate for return on invested capital (ROIC)" (first use of ROIC, before the gap below); tax = newest `damodaran_country.tax_rate` of the country when within [0, 1); else 21%. Gap `tax.fallback`: `Gap: ROIC tax falls back to the US 21% whenever the country has no Damodaran tax rate (or one outside [0, 1)), not to a rate of that country.`
- `ratios` (step) `@symbol bot.screener.engine.build_company_data`; note `ratios.formulas` (md list, these exact formulas): `net debt = total debt − cash`; `return on equity (ROE) = net income ÷ total equity`; `earnings per share (EPS) = net income ÷ diluted shares`; `P/E = close ÷ EPS, only when EPS > 0`; `book value (BV) per share = total equity ÷ diluted shares`; `P/BV = close ÷ BV per share, only when > 0`; `enterprise value (EV) ÷ EBITDA = (market cap + net debt) ÷ EBITDA`; `ROIC = EBIT × (1 − tax) ÷ (total debt + total equity)`; `free cash flow yield = free cash flow ÷ market cap`; `operating margin = EBIT ÷ revenue, per year`; histories (revenue, operating cash flow, diluted shares, operating margin) drop empty years; a missing input leaves the ratio empty. EBIT and EBITDA expanded before or at first use (earnings before interest and taxes; earnings before interest, taxes, depreciation and amortization).
- `usd` (decision) `@symbol bot.screener.engine._market_cap_usd`: market cap in USD = market cap × rate_to_usd of its currency on or before the market-cap date (from `currencies`); no rate → empty, so `min_market_cap` fails; no currency → taken as USD.
- `benchmark` (step) `@symbol bot.screener.benchmarks.load_industry_benchmarks`: sector benchmark = newest-year `damodaran_industry` row for (industry, region); industry = `industry_damodaran`, else the provider industry; looked up once per pair.

`coverage_gate` container ("2. coverage gate"):
- `gate` (decision) `@symbol bot.screener.engine.run_screen`, `@file docs/adr/0006-unmeasurable-companies-leave-the-universe.md`: "sector benchmark row for (industry, region) with a weighted average cost of capital (WACC)?\nno: the company leaves the universe before any rule runs,\nrecorded as rejected with coverage_gate\n(architecture decision record (ADR) 0006)". Edge to `persist_and_report.persist`.

`quality_gates` container ("3. quality gates: every gate must pass"), one decision per rule, key = rule name, `@rule <name>` and every `@param <name>.<p>` on its label line:
- `min_market_cap`: `market cap in USD ≥ 100M` · `missing: fails`.
- `min_years_history`: `annual rows ≥ 5`.
- `exclude_sectors` (+ `@const bot.screener.rules.DEFAULT_EXCLUDED_SECTORS` with `bank` and `insurance` on the line, `@symbol bot.reference.sectors.is_financial_services`): `fails when the Damodaran industry is a financial services label (exact match)` · `or the industry contains bank or insurance (any case)`.
- `max_net_debt_to_ebitda`: `net debt ÷ EBITDA ≤ 4` · `net debt ≤ 0: passes` · `EBITDA ≤ 0 with positive net debt: fails`.
- `min_interest_coverage`: `EBIT ÷ interest expense ≥ 2` · `interest expense ≤ 0: passes`.
- `positive_operating_cashflow`: `operating cash flow > 0 in ≥ 4 of the last 5 years` · `fewer than 5 years: fails`.
- `max_goodwill_to_assets`: `goodwill ÷ total assets ≤ 0.5` · `total assets ≤ 0: fails`.
- `all_pass` (decision) `@symbol bot.screener.engine.evaluate_company`: "every quality gate passed?\na missing datum fails the gate\nno: rejected". Note `all_pass.all_layers`: every layer still runs on a failing company, so its failed rules are all recorded.

`value_indicators` container ("4. value indicators: at least one must pass"):
- `pe_below_industry_multiple`: `P/E < 0.7 × sector median P/E` · `skipped: median or company P/E missing or ≤ 0`.
- `ev_ebitda_below_industry_multiple`: `EV/EBITDA < 0.7 × sector median EV/EBITDA` · same skip.
- `pbv_below_industry_multiple_with_roe_above_median`: `P/BV < 0.7 × sector median P/BV and ROE > sector median ROE` · `skipped: a median or company figure missing, or P/BV ≤ 0`.
- `fcf_yield_above`: `free cash flow yield > 8%` · `skipped when missing; no sector benchmark needed`.
- `score` (step) `@symbol bot.screener.rules._value_score`: `score = (threshold − value) ÷ threshold, clipped to [0, 1]` (threshold = 0.7 × sector median); `free cash flow yield: score = min(1, yield ÷ minimum)`; `value metric = highest score among passing indicators`.
- `at_least_one` (decision) `@symbol bot.screener.engine.evaluate_company`: "at least one value indicator passed?\na skipped indicator neither passes nor fails;\nall four skipped: rejected\nno: rejected".

`trap_detection` container ("5. trap detection: every detector must pass"):
- `growth_rate` (step) `@symbol bot.screener.rules._avg_growth_rate`: `average growth = mean of (current − previous) ÷ previous over consecutive years` · `undefined through a base ≤ 0`.
- `revenue_not_declining`: `average revenue growth over the last 3 years > −5%` · `uses the last 4 revenues; fewer, or undefined growth: fails`.
- `operating_margin_not_contracting`: `margin change = (last − first) × 10,000 bps over the last 3 years ≥ −200 bps` · `fewer than 2 margins: fails`.
- `roic_above_sector_wacc` (no params): `ROIC > sector WACC` · `ROIC missing: fails` · `sector WACC missing: skipped (never after the coverage gate)`.
- `sloan_accruals_below`: `Sloan ratio = (net income − operating cash flow) ÷ total assets < 0.1` · `missing or total assets ≤ 0: fails`.
- `share_count_not_diluting`: `average diluted share count growth ≤ 5% a year` · `fewer than 2 counts or undefined growth: fails`. Gap `share_count_not_diluting.mergers`: `Gap: spec §6.4 exempts dilution from justified mergers and acquisitions; the code caps growth unconditionally.`
- `all_pass` (decision) `@symbol bot.screener.engine.evaluate_company`: "every trap detector passed?\na skipped detector is eliminatory (ADR 0006)\nno: rejected" (ADR is expanded earlier, on the `coverage_gate.gate` label).
- Gap `auditor` (child of the `trap_detection` container): `Gap: spec §6.4 also lists auditor changes and late filings; not implemented.`

`ranking` container ("6. ranking of the survivors"):
- `metrics` (step) `@symbol bot.screener.engine._quality_metric`, `@symbol bot.screener.engine._growth_metric`, `@symbol bot.utils.finance.cagr`: `value = highest passing value-indicator score`; `quality = (ROIC − sector WACC) + ROE, missing ROE counts 0`; `growth = revenue compound annual growth rate (CAGR) = (last ÷ first)^(1 ÷ (years − 1)) − 1`; `0 when fewer than 2 years or first ≤ 0`. Gap `metrics.spec_scores`: `Gap: spec §6.5 puts margin stability in the quality score and free cash flow growth in the growth score; the code uses (ROIC − WACC) + ROE and revenue CAGR only.`
- `percentiles` (step) `@symbol bot.screener.ranking._percentiles`: `percentile = rank among distinct values ÷ (distinct values − 1)` · `ties share a percentile; one survivor or all values equal: 1.0` · over all survivors.
- `weights` (step) `@symbol bot.screener.ranking.RankingWeights`, `@param ranking.value`, `@param ranking.quality`, `@param ranking.growth`, `@param ranking.margin_of_safety`: `score = 100 × (0.40 × value + 0.30 × quality + 0.20 × growth + 0.10 × margin of safety)`; note `weights.bounds`: weights each in [0, 1], summing to 1, else the preset fails to load; the margin of safety is the raw intrinsic value ÷ price, not a percentile, so the score has no ceiling at 100.
- `first_pass` (step) `@symbol bot.screener.ranking.rank`, `@const bot.screener.ranking.PLACEHOLDER_MARGIN_OF_SAFETY`: `first pass: score every survivor with margin of safety 0.5` · `best first, ties by ticker`.
- `top_n` (decision; `top` is a d2 reserved keyword): `--top N given?\nyes: keep the best N; no: keep every survivor` (cites `@symbol bot.screener.engine.run_screen`).
- `second_pass` (step) `@symbol bot.screener.engine._batch_dcf_margins`: `second pass: value each kept ticker by DCF` · `margin of safety = intrinsic value ÷ price` · `with config/assumptions/TICKER.yaml when present`.
- `valued` (decision) `@const bot.screener.ranking.PLACEHOLDER_MARGIN_OF_SAFETY`: `valued?\nno (unknown ticker, missing data, incomplete assumptions):\nkeeps margin of safety 0.5`.
- `rescore` (step) `@symbol bot.screener.ranking.rescore_with_margins`: `re-blend the score with the real margin of safety` · `percentiles kept from the first pass over all survivors` · `re-sorted best first`.

`persist_and_report` container ("7. persist and report"):
- `persist` (step) `@symbol bot.screener.persist.persist_candidates`: one new run id; kept survivors: rank, score, value / quality / growth scores, margin of safety, passed and failed rules, passed = true; rejected companies: passed = false with their failed rules. Note `persist.cut`: survivors cut by `--top` are not written.
- `report` (step) `@symbol bot.reporting.screen_report.render_markdown`, `@symbol bot.reporting.screen_report.render_csv`: same columns in both (rank, ticker, name, sector, score, the four sub-scores, market cap, P/E, EV/EBITDA, P/BV, ROE, ROIC, free cash flow yield); header counts screened companies, shortlist size and coverage-gate exclusions.

Edges (all labelled), at least: `cli -> snapshot.load` ("preset loaded"); preset/files → `cli`; stores → the steps that read them (`companies`, `financials_annual`, `prices_daily` → `snapshot.load`; `damodaran_country` → `snapshot.region`, `snapshot.tax`; `currencies` → `snapshot.usd`; `damodaran_industry` → `snapshot.benchmark`); flow in order `snapshot.load -> snapshot.region -> snapshot.tax -> snapshot.ratios -> snapshot.usd -> snapshot.benchmark -> coverage_gate.gate`; `coverage_gate.gate -> quality_gates` ("yes: measured, every rule runs"); each quality gate → `quality_gates.all_pass`; each value indicator → `value_indicators.score` (or `at_least_one`); `value_indicators.score -> value_indicators.at_least_one`; `trap_detection.growth_rate` → `revenue_not_declining` and `share_count_not_diluting`; each detector → `trap_detection.all_pass`; layer verdicts → `ranking.metrics` ("survivors"); rejections ("failed rules") → `persist_and_report.persist`; `ranking.metrics -> ranking.percentiles -> ranking.weights -> ranking.first_pass -> ranking.top_n -> ranking.second_pass`; `assumptions -> ranking.second_pass`; `ranking.second_pass -> analyze_stage` ("ticker and override file"); `analyze_stage -> ranking.valued` ("margin of safety, or an error"); `ranking.valued -> ranking.rescore`; `ranking.rescore -> persist_and_report.persist` and `-> persist_and_report.report`; `persist_and_report.persist -> duckdb.screener_candidates`; `persist_and_report.report -> report_md`, `-> report_csv`.
