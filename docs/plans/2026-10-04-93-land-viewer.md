### Task 3: The workflow tests skip while the workflow file is missing

**Files:**
- Modify: `tests/unit/test_site_workflow.py` (`_load` only)

**Interfaces:** none. All three tests call `_load()` first, so a skip inside `_load` makes each of them call `pytest.skip` and leaves their assertions untouched.

- [ ] **Step 1: See it fail.** `uv run pytest -q tests/unit/test_site_workflow.py` → `3 failed` with `FileNotFoundError`.
- [ ] **Step 2: Implement.**

```python
import pytest
import yaml

_WORKFLOW = Path(__file__).resolve().parents[2] / ".github" / "workflows" / "site.yml"


def _load() -> dict[Any, Any]:
    if not _WORKFLOW.exists():
        pytest.skip("`.github/workflows/site.yml` is added by a human, see #92 (workflow scope)")
    data: dict[Any, Any] = yaml.safe_load(_WORKFLOW.read_text())
    return data
```

- [ ] **Step 3: Absent-file check.** `uv run pytest -q -rs tests/unit/test_site_workflow.py` → `3 skipped`, and every skip reason is the message above.
